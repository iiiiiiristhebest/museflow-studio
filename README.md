# MuseFlow · 灵感录音室

一个可在浏览器中直接运行的音乐创作工作台原型。打开 `index.html` 即可体验，无需安装或注册。

## 可以实际操作的流程

- 在多轨波形上定位、拖选片段并循环试听；逐轨调节音量、声像、静音和独奏。
- 选择风格、节奏、调性与力度，对选区生成可听见差异的本地合成编配；使用版本快照和撤销比较结果。
- 独立编辑歌词，导入音频，录制人声并加入混音。
- 将作品保存到浏览器、导入或导出完整项目 JSON，并导出混音 WAV、歌词 TXT 和作品卡片 PNG。

## 原型边界

编配使用浏览器内的参数驱动合成，并未接入音乐生成模型；作品数据保存在当前浏览器的 IndexedDB 中。项目 JSON 可用于备份或迁移。浏览器录音需要麦克风权限。

## 使用

直接打开 `index.html`。桌面浏览器能完整展示多轨工作区；手机浏览器提供纵向布局。推荐使用新版 Edge 或 Chrome。

## 设计与实现

独立产品概念项目。单文件包含界面、交互、浏览器音频处理和本地存储；原型不依赖第三方服务。发布页不提供账号体系或云端同步。
